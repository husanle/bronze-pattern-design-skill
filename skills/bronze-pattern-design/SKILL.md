# Bronze Pattern Design / 青铜纹样产品设计

## 中文

按请求执行“辨识”“重绘”“产品转译”或“展板”所需的环节。沿用用户已确定的品类、风格、品牌边界和交付格式，不强行做全套。

1. **辨识与记录。** 先看整张参考和展签，再逐个读局部。区分主纹、地纹和边饰；记录轮廓、朝向、对称轴、关键单元、重复方向和可疑缺损。每款纹样分别标明来源、展签原名或暂定名、可见依据及不确定处。没有可靠展签或馆藏记录，不由纹样外形断代、定器物或推定象征意义。形态对照见 [纹样识读](references/motif-field-guide.md)。
2. **重绘与核对。** 默认保留一张可比对的原纹重绘；按需另做产品图形，不把简化设计叫作复原。先看干净局部，保留原图的数量、朝向、比例、正负形、连接和重复关系；反光、残缺不可凭空补造。用户指定 ImageGen 时优先用局部作参考，请它去除摄影噪声而不重构纹样；与源图逐项复核。工具不可用就说明，不宣称已生成。ImageGen 图通常是位图；只有实际构建并检查了矢量路径，才交付为可编辑矢量。
3. **按使用区域上物。** 先列实际动作与不得遮挡的区域，再选单枚、窄带或平铺。每件产品说明纹样、位置、材料／工艺、日常用途和样件检查点。先做实际尺寸的单色样：防止刻度、握位、文字、开口、折线和书写区被挤占。工艺参数没有供应商依据时，标为打样目标。见 [产品与展板](references/product-and-board.md)。
4. **按用途交付。** 把原图局部、近源重绘、产品应用稿和效果图区分开。展板可采用“左大产品图、右上重绘、右下来源”，但用户指定布局优先。黑白打印用白底、深字和灰阶图，导出指定纸型后按实际页尺寸检查裁切、字重与纹样辨识。遵循用户的标注偏好：可省去可见编号，但保留可查的内部对应关系。只在允许再用时把照片、标识和第三方图形打进外发包。

## English

Run only the stages needed: identification, redraw, adaptation, or presentation board. Preserve the requested products, style, brand boundaries, and deliverables.

1. **Read and record.** Inspect the full reference and its label before inspecting details. Separate principal ornament, ground pattern, and borders. Record silhouette, direction, symmetry axis, units, repeat direction, and uncertainty or damage. For each motif, keep the source, quoted label or tentative name, visible evidence, and limitations. Do not date an object, identify it, or infer its symbolism from a motif alone. See the [motif field guide](references/motif-field-guide.md).
2. **Redraw and compare.** Keep a source-faithful study and, when needed, a separate production-oriented adaptation. Work from clean crops; retain counts, direction, proportions, positive and negative shapes, joins, and repeat logic. Do not invent details hidden by glare or damage. If the user requests ImageGen, use the crop as reference, ask to remove photographic noise without redesigning the motif, then compare the result against the source. State when the tool is unavailable. Treat image-generation output as raster unless actual editable vector paths have been built and checked.
3. **Design around use.** Map real actions and protected areas first, then choose an isolated motif, border strip, or repeat. For each item list motif, placement, material/process, practical feature, and prototype check. Proof at actual size in one color; keep graduations, grips, text, openings, folds, and writing zones clear. Mark unverified production values as prototype targets. See [products and boards](references/product-and-board.md).
4. **Deliver for the target use.** Distinguish source crops, close redrawing, application artwork, and renders. A useful board layout is products large on the left, redrawn motifs top right, sources bottom right; user preferences take precedence. For monochrome printing use white, dark type, and grayscale images. Verify the exported page size, clipping, legibility, and motif detail. Omit visible identifiers when requested, but retain the mapping in working files. Include photos, marks, and third-party graphics in shared bundles only when reuse is permitted.
